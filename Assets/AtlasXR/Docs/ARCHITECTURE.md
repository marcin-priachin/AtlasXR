# AtlasXR Architecture

This document is the home for the AtlasXR runtime architecture notes.

## Structure

- `Scripts/App`: application states and bootstrap entry points.
- `Scripts/Core`: shared events, services, dependency injection, logging, and state machine foundations.
- `Scripts/XR`: XR input, hands, passthrough, interaction, and highlighting systems.
- `Scripts/Procedures`: procedure runtime, data definitions, and validation.
- `Scripts/AI`: AI runtime integration, tools, and prompts.
- `Scripts/Voice`: speech-to-text and text-to-speech integrations.
- `Scripts/Backend`: authentication, API, and analytics integrations.
- `Scripts/UI`: views and presenters.
- `Scripts/Shared`: extensions and utilities.
